# Changelog

All notable changes to **Signal Foundry**, the Shooter visual overhaul.

## Unreleased · Signal Foundry visual overhaul

### Added
- 31 Blender-authored FBX exports covering the first-person rig, six enemies,
  the Warden, the arena, pickups and combat effects. Editable Blender scenes
  and Python generators are in `assets_src/`.
- Six HUD PNG sprites authored by the lead (reticle, horizontal and vertical
  reticle bars, hit marker, plate and phase pip), rendered from the editable
  `assets_src/HUD.blend` via `assets_src/build_hud.py`.

### Changed
- FoundryArena is now generated by the Editor build script and selected as the
  scene for builds; the original Arena scene, prefabs and assets are retained.
- Added Foundry FBX import handling and per-clip slicing of the actor models.
- Wired in the arena props and pickups, the effects and the HUD sprites.

### Verified
- All 31 FBXs re-imported in Blender. Reviewed the Warden and first-person poses.
- Unity 6000.6.10f1 generated the scene and built the Windows player with no errors.
- Self-tests passed 189/189, scene validation passed 179/179, and the Warden
  play-mode simulation passed 36/36. The Windows player passed a startup smoke test.
